# 马拉松赛务判定中枢

本项目用于组织大型马拉松的报名核验、分枪检录、计时判定、奖励公示和现场救治资源调度。赛务数据以事件形式进入，来源设备可能短时离线，所有业务时间均保留原始时区并换算为 UTC。

`fixtures/sample.json` 描述一场四万人规模赛事的基础参数，包括全程与半程人数、四个发令批次、奖励范围以及医疗资源。人脸信息仅使用外部模板引用，仓库不保存照片或生物特征原文。

执行 `python3 service.py --check` 可检查基础配置，运行 `python3 -m unittest -v` 可核对服务身份和样例结构。服务启动后，`/health` 返回当前项目标识。
